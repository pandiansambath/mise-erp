# chest.glb

A pirate treasure chest, from **Poly Pizza** (https://poly.pizza/m/haqf9qoiOG)
by **dook**, released under **CC0** — public domain, no attribution required.
Credited anyway, because knowing where a file came from is the difference
between an asset and a liability.

Chosen over the alternatives because its lid is a SEPARATE node (`Chest_Top`
beside `Chest_Base`), which is what lets it be hinged and thrown open. A chest
modelled as one welded mesh would have to be faked.

Loaded only on /award, and only after the page has rendered.
